# 合成氨 AI 生产调度专家平台

这是面向云图控股命题“如果你来到全球领先的合成氨生产装置现场，如何用 AI 打造一个生产调度专家？”构建的可演示原型。

## 交付内容

- `index.html`：可离线打开的调度专家平台首页。
- `assets/styles.css`：界面样式。
- `assets/app.js`：场景调度、约束解释、价值测算与 Gantt 展示逻辑。
- `assets/process-map.svg`：合成氨到复合肥协同的装置流程图。
- `data/plant-model.json`：示例装置、订单、约束和 KPI 数据模型。
- `docs/research-brief.md`：开题报告 part 1、part 2、出题意图和资料依据。
- `docs/architecture.md`：平台架构、核心模块、落地路线和推广价值。
- `docs/optimization-roadmap.md`：本轮优化补充的大框架、评审追问点和实施优先级。
- `docs/feishu-integration.md`：飞书机器人消息、审批、事件回调和授权边界设计。
- `提交材料/00_报名表填写文本.md`：按截图字段整理的可直接粘贴文本、附件建议、链接说明和队伍人数。
- `提交材料/00_报名表填写文本.docx`：同上，Word 版，适合作为第一份补充材料上传。
- `提交材料/01_开题报告.docx`：按参赛要求整理的 Word 开题报告。
- `提交材料/02_整体解决方案书.docx`：面向企业试点和评审的完整方案书。
- `提交材料/03_调控师操作手册.docx`：从当班调控师视角写的操作流程和异常处置。
- `提交材料/04_参考文献与数据依据.docx`：方案引用文献、行业资料和支撑关系。
- `提交材料/05_企业评审视角优化清单.docx`：从企业评审角度补强安全、收益、责任、数据、推广和创新辨识度。

## 使用方法

直接用浏览器打开：

```powershell
start D:\云图——合成氨\index.html
```

也可以启动一个本地静态服务：

```powershell
cd D:\云图——合成氨
python -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 方案定位

平台把合成氨装置看作“能源、设备、库存、下游需求、安全环保”共同约束下的动态排产问题。AI 不是替代班长，而是把 DCS/MES/ERP/LIMS/设备状态和市场订单融合成一个可解释的调度专家，给出班次级建议、风险边界、经济收益和回写闭环。

## 本轮优化补强

- 前端新增“平台总框架、数据就绪度、模型治理、异常工况预案”模块。
- 方案新增数据治理、模型漂移、审批留痕、灰度上线、安全降级和组织协同设计。
- 交互逻辑会根据订单、能价、设备健康、库存等变量动态调整治理状态和应急建议。
- 评审表达从“一个 AI 调度页面”升级为“可上线、可审计、可复盘的工业 AI 平台”。
- 最新版本继续补充企业试点清单、班组使用流程、验收与停用条件，避免方案停留在概念层。
- 最新版本将“开题报告、方案书、参考文献”从网页中移出，作为独立 Word 提交材料；网页只保留企业调控操作台。
- 最新版本根据补充试题升级为“超级数字员工”：新增成本寻优雷达、三案比选、执行监督闭环、知识库自学习，并在 Word 材料中回应调度寻优难、指挥效率低、知识传承难。
- 最新版本融入飞书协同：新增飞书调度卡片、负荷调整审批草稿、复盘同步日志和上线授权说明。
- 最新版本将页面中的自评分模块改为“专家审核关注点”，让企业专家看到待确认事项、审批责任和试点条件，而不是参赛方自我打分。
- 最新版本新增“创新落点闭环”，用反事实收益归因、安全护栏链、未采纳学习和协同触达突出平台差异化。

## 企业落地边界

- MVP 先做“建议与复盘”，不直接改 DCS/SIS 控制逻辑，不自动开停车。
- 先接少量高价值接口：MES 日计划、ERP 订单、罐区库存、DCS 摘要点、设备健康评分。
- 先影子运行 4-6 周，用历史和实时班次对比人工调度，不影响原生产组织。
- 收益只按被采纳方案的实际差额计算，剔除市场价格自然波动和检修计划外部影响。
- 数据延迟、模型低置信、安环红线接近时自动降级为规则建议和人工流程。
- 飞书只承担通知、审批、复盘和知识沉淀，不直接触碰 DCS/SIS 控制参数；真实上线需要企业自建应用授权。
