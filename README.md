# 氨智领航调控师

本仓库交付合成氨班次调度演示平台、样例数据、飞书协同链路和试点文档。页面数据用于验收演示，不代表企业实时工况。企业试点需确认订单、MES、生产历史数据库、设备与财务数据接口；系统不提供DCS/SIS写入能力，也不下达自动开停车指令。

## 解决的问题

- 产供销协同：在安全和连续生产约束下，比较液氨分配、下游负荷、外采安排和停运评估方案。
- 跨装置协调：当下游需求、公用工程、能源或库存发生变化时，给出负荷调整顺序和撤销条件。
- 设备趋势异常提示：展示振动、轴位移、防喘振裕度、轴承温度和床层温升等趋势证据，不冒充DCS报警。
- 经验管理：记录方案、确认、执行偏差和未采纳原因，经专业人员审核后进入调度案例库。

## 当前可验收内容

- 当班事件队列：按P1/P2/P3显示事件、影响范围、责任人和下一步动作。
- 班次调度事实表：保留数据来源、时间戳、单位、质量状态和责任专业。
- 24小时液氨平衡：核对期初可用量、预计产量、外采、各去向分配和期末可用量。
- 相对外售分配贡献账本：比较不同液氨去向的24小时测算值，不表示已经实现的收益。
- 执行监督演示：建议值与实际值分开显示；企业联调前不构造DCS实际负荷。
- 飞书已验证链路：在线方案稿、飞书多维表格样例库、Task v2任务清单和验收任务`t136777`。
- 飞书演示原型：互动卡片、负荷调整审批状态机和事件回传字段契约。
- 待企业授权：目标群机器人、审批定义、Aily知识源、事件订阅及MES和生产历史数据库接口。

## 试点范围

| 阶段 | 范围 | 主要交付 |
| --- | --- | --- |
| 30天 | 仅校核订单导出、MES班次计划、罐区历史摘要、飞书协同记录四类离线或只读数据 | 字段字典、样例、质量报告、责任专业和接口清单 |
| 60天 | 扩展生产历史数据库、设备和公用工程只读数据，开展旁路回放 | 调度建议、人工方案、偏差报告和停用条件验证 |
| 90天 | 覆盖不少于30个有效班次及三类场景，开展低风险执行验证 | MES计划摘要、飞书任务、班后复盘、规则版本和验收报告 |

## 系统边界

- DCS、SIS、APC和设备保护系统继续承担控制、报警和保护。
- 平台从生产历史数据库或经批准的只读接口获取工况摘要，不提供DCS/SIS写入路径。
- 数据过期、质量码无效、输入超出适用工况范围或安全与设备限值接近时，平台停止给出可执行建议并转人工处理。
- 班后记录先进入待审核案例库，未经生产、设备或安环专业审核，不更新生产规则。

## 提交材料

- `00_提交信息汇总.docx`：在线表单填写索引，收录Part 1、Part 2定稿、附件用途和体验链接，不作为主方案正文。
- `01_开题报告_决赛更新稿.docx`：本次决赛开题报告定稿，集中回答命题理解、方案思路和资料依据；原同名文档当前由 Word 占用，请以更新稿为准。
- `02_整体解决方案书.docx`：系统实施方案，说明业务流程、数据接口、约束模型、部署边界、试点步骤和验收方法。
- `03_调控师操作手册.docx`：班组使用手册，说明调度员、班长和专业人员在班前、班中、班后的具体操作。
- `04_参考文献与数据依据.docx`：证据来源与口径说明，记录事实来源、使用位置、适用边界及仍需企业确认的数据。
- `05_方案创新与落地清单.docx`：交付状态与试点验收清单，区分已验证、演示原型、待授权和试点工作。
- `06_决赛完整方案文档.docx`：参赛方案主文档，用典型班次串联问题、平台操作、飞书协同、结果复核和实施计划。
- `07_飞书功能模块说明.docx`：飞书协同与接口说明，说明卡片、审批、Task v2、多维表格、智能问答和事件回传。
