# 飞书功能接入说明

## 接入边界

飞书负责调度建议的送达、确认、任务跟踪和班后记录。生产控制仍由DCS、SIS、APC、设备保护系统和现场操作制度承担。飞书操作不直接改变控制参数，也不替代操作票和现场签字。

- 飞书多维表格样例库：`https://www.feishu.cn/base/QzENbAkl1aYQGds8dBacqu6Inue`

验收任务验证“建议确认、责任到人、截止时间、执行状态、复盘结果”链路，并明确不写DCS/SIS、不替代联锁和操作票。

## 原型

### 互动卡片

卡片显示建议编号、目标负荷、处置状态、数据时间、触发字段、相对外售分配贡献、有效期和撤销条件。按钮包括“提交确认”“要求复核”“驳回并说明原因”。按钮操作以`shift_id + proposal_id + action_id`防止重复处理。

### 审批状态机

`草稿 -> 待班长确认 -> 已批准 -> 四岗位接令 -> 执行跟踪 -> 班末复盘 -> 归档`

一般提示不自动创建审批；调度员决定提交方案后，由班长确认。设备、公辅、库存等已登记条件成立时，增加调度主管和对应专业会签。审批通过后生成跨装置调度动作单，由合成主操、硝酸主操、罐区/调度和公辅调度分别接令。四岗位全部接令后才进入执行跟踪；接令不等于现场已经执行。审批结果只允许写入MES计划摘要、交接说明和复盘记录。

命中演练停算线时，不再生成新目标、经济排序、动作单或审批；平台维持最近批准方案并提示转现场规程。解除条件由对应专业确认后，才允许基于新快照重新计算。

### 跨装置调度动作单

动作单按`班次编号 + 方案版本 + 岗位`拆分，记录接令人、接令时间、回复、异常、有效期和撤销条件。任一岗位退回、超时或发现版本不一致时，保留原计划并返回调度重新计算。实际负荷、库存和能耗只从Historian或企业认可的只读事实源回传，无回传时保持为空。

- 已验证：Task v2普通任务写入。
- 原型：四岗位动作单、全部接令门禁和状态汇总。
- 待授权：岗位身份映射、审批自动拆单、事件订阅和Historian只读接口。

### 事件回传

计划接收卡片操作、审批状态、任务关闭和复盘提交事件。服务端必须验签、防重放、防重复处理，并将失败事件放入待处理队列。

## 待授权

- 目标调度群机器人范围。
- 审批定义`ammonia_load_adjustment`及表单字段。
- Aily知识源、数据知识问答权限和工具动作。
- 事件订阅、回调地址及服务端密钥配置。
- MES和生产历史数据库接口。

原生任务AI智能体登记尚受平台准入限制，不列为已交付能力。当前生产协同设计使用“项目机器人、Task v2和人工审批”，待飞书开放平台确认租户准入后再评估原生智能体。

## 数据记录

飞书多维表格至少记录：班次、场景、建议编号、目标负荷、处置状态、触发字段、数据时间、24小时相对外售分配贡献测算值、采纳状态、未采纳原因、实际负荷、执行偏差、班长备注、审核人和适用条件。

班后记录先进入待审核案例库。生产、设备和安环专业审核通过后，才可修订规则或作为模型训练样本；单次采纳结果不自动改变生产规则。

## 转人工条件

- 数据过期或质量状态无效。
- 关键字段缺失或口径冲突。
- 输入超出模型适用工况范围。
- 安全、设备或环保限值接近。
- 建议不能说明数据来源、约束和撤销条件。

触发任一条件后，平台保留原计划，只显示数据问题和人工复核任务。
