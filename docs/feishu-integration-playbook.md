# 飞书功能接入说明

## 接入边界

飞书负责调度建议的送达、确认、任务跟踪和班后记录。生产控制仍由DCS、SIS、APC、设备保护系统和现场操作制度承担。飞书操作不直接改变控制参数，也不替代操作票和现场签字。

## 演示原型

### 互动卡片

卡片显示建议编号、目标负荷、风险等级、数据时间、触发约束、相对外售分配贡献、有效期和撤销条件。按钮包括“提交确认”“要求复核”“驳回并说明原因”。按钮操作以`shift_id + proposal_id + action_id`防止重复处理。

### 审批状态机

`草稿 -> 待班长确认 -> 已批准 -> 执行跟踪 -> 班末复盘 -> 归档`

低风险建议由班长确认；高风险建议增加调度主管和相关专业会签。审批通过后只允许写入MES计划摘要、交接说明和复盘记录。

### 事件回传

计划接收卡片操作、审批状态、任务关闭和复盘提交事件。服务端必须验签、防重放、防重复处理，并将失败事件放入待处理队列。

## 待企业授权

- 目标调度群机器人范围。
- 审批定义`ammonia_load_adjustment`及表单字段。
- Aily知识源、数据知识问答权限和工具动作。
- 事件订阅、回调地址及服务端密钥配置。
- MES和生产历史数据库接口。

原生任务AI智能体登记尚受平台准入限制，不列为已交付能力。当前生产协同设计使用“项目机器人、Task v2和人工审批”，待飞书开放平台确认租户准入后再评估原生智能体。

## 数据记录

飞书多维表格至少记录：班次、场景、建议编号、目标负荷、风险等级、数据时间、24小时相对外售分配贡献测算值、采纳状态、未采纳原因、实际负荷、执行偏差、班长备注、审核人和适用条件。

班后记录先进入待审核案例库。生产、设备和安环专业审核通过后，才可修订规则或作为模型训练样本；单次采纳结果不自动改变生产规则。

## 转人工条件

- 数据过期或质量状态无效。
- 关键字段缺失或口径冲突。
- 输入超出模型适用工况范围。
- 安全、设备或环保限值接近。
- 建议不能说明数据来源、约束和撤销条件。

触发任一条件后，平台保留原计划，只显示数据问题和人工复核任务。
