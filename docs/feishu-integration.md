# 飞书协同集成设计

## 定位

飞书不是控制层，而是合成氨调控师的协同、审批、复盘和知识沉淀入口。平台仍坚持 DCS/SIS 守底线，飞书只承载“谁看到、谁确认、谁审批、执行后效果如何”的管理闭环。

## 当前原型已加入

1. **飞书调度卡片预览**：自动把当前目标负荷、日产氨、吨氨收益、风险指数、审批要求和执行边界组成卡片。
2. **飞书审批字段**：为“合成氨负荷调整审批”预置申请事项、业务理由、关键约束、回写范围和回调事件。
3. **协同日志**：点击“生成群卡片 / 生成审批单 / 同步复盘”后，本地记录草稿动作。
4. **调控师快捷按钮**：左侧调控师指令窗口新增“飞书卡片、发起审批、复盘同步”。
5. **授权状态**：未配置 App ID/Secret 时只进行本地预览，不会真实发送消息。

## 上线流程

### 1. 机器人通知

适用场景：班前会、班中重算、异常提醒、交接班摘要。

需要飞书能力：

- 企业自建应用。
- 启用应用机器人。
- 机器人进入“合成氨当班调度群”。
- 服务端获取访问凭证后调用消息 API。

卡片字段：

- 运行模式：稳氨、保供、护机。
- 目标合成负荷：例如 86%。
- 触发约束：氢氮比、合成塔床层温升、循环压缩机、液氨库存。
- 风险指数与置信度。
- 按钮：确认采纳、发起审批、查看约束、记录未采纳原因。

### 2. 负荷调整审批

适用场景：风险较高、设备边界接近、库存偏低、订单冲刺等需要留痕的负荷调整。

需要飞书能力：

- 企业管理员创建审批定义。
- 获取审批定义 `approval_code`。
- 后端服务使用审批 API 创建审批实例。
- 审批通过后只允许写 MES 计划、交接摘要和复盘记录，不直接写 DCS/SIS。

审批表单字段：

- 申请装置：合成氨。
- 运行模式：稳氨/保供/护机。
- 目标负荷。
- 业务理由。
- 触发约束。
- 风险指数。
- 预计影响：吨氨能耗、库存、订单满足率。
- 回滚条件。

### 3. 事件回调与知识库

适用场景：审批通过、审批驳回、卡片按钮点击、班后复盘提交。

需要飞书能力：

- 配置事件订阅或回调公网地址。
- 后端校验飞书事件签名/挑战。
- 将事件写入“合成负荷指令库、异常经验库、未采纳原因库”。

事件进入知识库的字段：

- 输入快照。
- 系统方案。
- 审批人。
- 采纳/未采纳。
- 实际执行负荷。
- 氢氮比和床层温升偏差。
- 液氨库存变化。
- 吨氨成本结果。
- 班长备注。

## 接入所需授权信息

真实接入飞书时，需要以下信息，不能写在前端仓库里：

1. 飞书企业自建应用的 `App ID`。
2. 飞书企业自建应用的 `App Secret`。
3. 目标群或目标用户的接收范围。
4. 是否已启用应用机器人能力。
5. 合成氨负荷调整审批的 `approval_code`。
6. 事件订阅/回调的公网地址或内网代理方案。
7. 企业管理员开通的消息、审批、事件订阅权限范围。

## 后端环境变量

```text
FEISHU_APP_ID=cli_xxx
FEISHU_APP_SECRET=xxx
FEISHU_TARGET_CHAT_ID=oc_xxx
FEISHU_APPROVAL_CODE=xxx
FEISHU_EVENT_SECRET=xxx
FEISHU_ENCRYPT_KEY=xxx
```

## 安全边界

- 不在浏览器前端保存 App Secret。
- 不让飞书按钮直接控制 DCS/SIS。
- 高风险方案必须审批。
- 所有飞书回调都要校验来源。
- 系统方案、人工确认、执行偏差、复盘结论必须留痕。
