# 业务范围与试点边界

## 业务范围

平台按四项能力组织，不再使用“赛道”和“底座”作为文档层级：

1. 产供销协同：比较液氨去向、装置负荷、外采安排和停运评估方案。
2. 跨装置协调：处理下游需求、公用工程、能源和库存变化。
3. 设备趋势异常提示：显示趋势证据、检查项和通知专业，不替代DCS报警。
4. 经验管理：记录方案、确认、执行偏差和未采纳原因，经专业人员审核后复用。

## 试点边界

- 30天只校核订单导出、MES班次计划、罐区历史摘要和飞书协同记录四类离线或只读数据。
- 60天扩展生产历史数据库、设备和公用工程只读数据，开展旁路回放。
- 90天覆盖不少于30个有效班次和产供销重排、公辅波动吸收、设备趋势复核三类场景；只选择未命中演练停算线且审批条件完整的场景进行执行验证。
- 平台不提供DCS/SIS写入路径，不下达自动开停车指令。
- 数据不合格、输入超出适用工况范围或安全与设备限值接近时，停止给出可执行建议并转人工处理。
- 24小时指标称为相对外售分配贡献测算值；生产效果以企业试点数据为准。

## 飞书交付状态

- 已验证：在线方案稿、多维表格样例库、Task v2任务清单和验收任务`t136777`。
- 原型：互动卡片、负荷调整审批状态机、跨装置动作单门禁和事件回传字段契约。
- 待授权：目标群机器人、审批定义、四岗位身份映射、Aily知识源、事件订阅和企业系统接口。

## 审批后的岗位接令

审批通过后，合成主操、硝酸主操、罐区/调度和公辅调度分别接收同一方案版本的动作单。四岗位全部接令后才进入执行跟踪；接令只表示收到方案并确认责任，不作为实际执行凭证。实际负荷、库存和能耗只从Historian或企业认可的只读事实源回传，无回传时保持为空。

## 条件处置与停算

- 一般提示：展示具体偏差、持续时间和核对事项，不自动升级审批。
- 专业会签：设备、公辅、库存等已登记条件成立时，路由至对应专业；条件由字段、时间窗、质量状态和规则版本共同描述。
- 演练停算线：触发后停止新目标、经济排序、动作单和审批，维持最近批准方案并转现场规程。审批不由汇总分数驱动。

预登记验收目标为数据可用率不低于98%、物料平衡残差不高于1.5%、快照重算P95不高于120秒、调度决策中位耗时较基线缩短不低于30%。以上均为试点定义稿，30天数据校核后由企业冻结口径。
