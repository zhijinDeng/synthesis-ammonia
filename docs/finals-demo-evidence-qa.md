# 决赛演示、班次证据链与试点验收

## 使用说明

本文件用于统一决赛现场演示、答辩口径和企业试点验收。演示中的价格、库存、负荷和设备趋势均为场景样例，不代表云图现场实时数据；现场数据、阈值、责任人和财务口径需在企业授权后确认。

交付状态始终分为三类：

- 已验证：本地交互工作台、飞书在线方案稿、多维表格样例库、Task v2任务清单和验收任务`t136777`。
- 原型：互动卡片、负荷调整审批状态机、典型班次证据链、事件回传字段契约和班后案例审核流程。
- 待授权：目标调度群机器人、审批定义、Aily知识源、事件订阅，以及ERP、MES、生产历史数据库、APC、设备和公用工程接口。

演示收束语：平台交付的不是一个替代操作员的自动控制器，而是一套能够把班次事实、调度判断、责任确认和执行结果串起来的工作方法。企业试点的第一步，是用真实班次检验它是否让调度更快、更稳、更容易复盘。

补充动作：在当班工作区点击“导出当前方案证据包”。下载文件应包含输入快照、行情版本、门禁状态、24小时物料平衡、四岗位动作单、接令状态、飞书流转边界和审计事件。现场说明：这是可交接、可复核的本地 JSON 证据，不是自动上传，也不等同于飞书审批或生产执行。

### 跨装置调度动作单

| 接令岗位 | 接令时核对 | 接令后的责任 | 未接令或退回处理 |
| --- | --- | --- | --- |
| 合成主操 | 合成氨目标负荷、升降负荷节奏、保持条件和撤销条件 | 确认本装置收到有效版本，并按现行操作票组织现场执行 | 保留原计划，反馈约束或不可执行原因 |
| 硝酸主操 | 下游目标负荷、耗氨窗口、缓冲能力和恢复条件 | 确认下游承接节奏与现场条件 | 退回调度重算液氨去向与负荷方案 |

动作单以`班次编号 + 方案版本 + 岗位`作为唯一接令对象，记录接令人、接令时间、回复、异常和有效期。审批通过只表示方案具备下发条件；四岗位全部接令只表示责任链已确认。接令不等于实际执行，真正的执行状态必须来自生产历史数据库或企业认可的只读事实源，接令时间、任务完成按钮或人工备注均不能替代实际值。

## 三、评委追问及事实回答

### 1. 这套方案和普通看板有什么区别？

看板主要展示状态，本方案还保存原计划、输入快照、约束校核、候选方案、人工确认、执行回传和班后复盘。每条建议都能追到使用了什么数据、为什么提出、谁确认、执行结果怎样。

### 2. 为什么不让系统直接控制DCS？

DCS、SIS、APC和设备保护承担控制、报警和保护。我们的平台位于生产运行管理层，处理跨装置、跨岗位的班次决策。审批通过后最多写入MES计划摘要、交接说明和复盘记录，不提供DCS/SIS写入路径。

### 3. 目前哪些飞书功能已经做通？

已验证在线方案稿、飞书多维表格样例库、Task v2任务清单和验收任务`t136777`。互动卡片、负荷调整审批状态机和事件回传字段契约是原型。目标群机器人、审批定义、Aily知识源、事件订阅和企业系统接口仍待授权。

跨装置动作单的业务流程已形成原型；Task v2普通任务写入已经验证。根据审批结果自动拆分四岗位任务、汇总接令状态并驱动门禁，需要目标人员范围、事件订阅和企业应用权限，属于待授权能力。

### 4. 没有企业实时数据，方案如何证明有效？

当前证明的是业务流程、计算口径、控制边界和可追溯性，不声称已经取得现场效果。试点先校核数据，再做旁路回放，最后选择未命中演练停算线且审批条件完整的场景执行验证；所有效果指标都以企业确认的基线和真实回传数据计算。

### 5. 经济指标为什么不是“节约金额”？

演示采用相对液氨外售基准的分配贡献，用于比较液氨去向。它由产品净收入、非氨变动成本、包装物流、启停摊销、液氨机会成本和经确认的违约避免额组成。只有建议被采纳、实际执行并完成归因后，才统计试点效果。

### 6. 系统如何处理错误数据或错误建议？

关键字段缺失、数据过期、口径冲突、输入超出适用工况范围，或安全与设备限值接近时，平台停止给出可执行建议，保留原计划并创建人工复核事项。任何建议都要带有效期、撤销条件和责任人。

### 7. 系统如何学习，又怎样避免越学越错？

班后记录先进入待审核案例库。生产、设备、安环和经营专业确认事实、归因和适用条件后，才允许修订规则或纳入训练样本；单个班次不会自动改变生产规则，所有版本保留审核人与撤销路径。

### 8. 与MES、APC和RTO是什么关系？

MES承接计划和执行记录，APC处理装置内先进控制，RTO负责经确认范围内的实时经济优化。本平台汇总跨装置班次事实、比较候选方案并组织人工确认，向这些系统提供或接收经过授权的摘要信息，不替代其原有职责。

### 9. 90天试点怎样判断是否通过？

先看安全硬约束、数据质量、建议可复算、审批合规和实际值真实性等必过项；再覆盖不少于30个有效班次和产供销重排、公辅波动吸收、设备趋势复核三类场景，比较调度用时、库存偏差、订单满足、单位氨变动成本和趋势提示提前量。

### 10. 方案落地最先需要企业提供什么？

首批只需要四类离线或只读数据：订单导出、MES班次计划、罐区历史摘要和飞书协同记录，同时由经营、生产、罐区、财务和信息化人员确认字段口径、时间戳、单位、更新频率和责任专业。

## 五、试点验收口径

### 有效班次定义

一个有效班次应同时满足：原计划在建议生成前冻结；必需输入具有来源、时间戳、单位和质量状态；建议及其版本可追溯；人工确认结果完整；已执行方案具有生产历史数据库回传和班后复盘。未执行方案可用于流程验收，但不进入效果统计。

### 必过项

1. 安全边界：安全硬约束零突破；平台不存在DCS/SIS写入路径，不替代报警、联锁、操作票和现场确认。
2. 数据真实性：关键字段缺失、过期或质量状态无效时必须降级人工；无生产历史数据库回传时实际值保持为空。
3. 可复算性：液氨物料守恒、相对外售分配贡献和候选方案排序能够按同一输入快照复算。
4. 条件处置：一般提示、专业会签条件和演练停算线均能追到具体字段、时间窗、质量状态和规则版本；审批不由汇总分数驱动。
5. 动作单门禁：审批通过后四岗位分别接令，未全部接令不得进入执行跟踪；接令状态不得填入实际执行字段。
6. 覆盖范围：90天阶段不少于30个有效班次，并覆盖产供销重排、公辅波动吸收、设备趋势复核三类场景。

### 预登记目标

| 指标 | 定义稿口径 | 目标 |
| --- | --- | --- |
| 数据可用率 | 新鲜度窗口内且质量状态合格的必需记录数 / 应到必需记录数 | 不低于98% |
| 物料平衡残差 | `|期初可用量+期间产量+外采-各去向-期末可用量| / (期初可用量+期间产量+外采)` | 不高于1.5% |
| 快照重算P95 | 合格快照冻结至方案、约束证据和测算明细生成完成的95分位耗时，不含人工确认 | 不高于120秒 |
| 调度决策中位耗时缩短 | `1-试点同类场景决策中位耗时/基线中位耗时` | 不低于30% |

以上指标是试点定义稿，不表示当前已达到。字段范围、分母、时间起止点、基线期、场景分层和排除项在30天数据校核后由企业冻结。

### 观察指标

| 指标 | 计算口径 | 使用边界 |
| --- | --- | --- |
| 数据完整率 | 合格必需字段数 / 应有必需字段数 | 必需字段和阈值在30天阶段由双方冻结 |
| 数据及时率 | 在约定新鲜度窗口内到达的记录数 / 应到记录数 | 各数据域分别设定窗口，不使用统一延迟假设 |
| 调度用时 | 从事实表可用到班长形成决定的时间 | 与同类场景人工基线比较 |
| 订单满足率 | 按期完成且质量合格的订单量 / 应完成订单量 | 排除双方确认的不可控外部事件 |
| 库存偏差 | 实际期末库存与批准方案目标库存之差 | 同时检查安全库存，不以贴近目标替代安全判断 |
| 单位氨变动成本 | 经财务确认的变动成本 / 合格氨产量 | 固定成本吸收单列解释，不重复计入 |
| 分配贡献偏差 | 实际口径测算值与建议测算值之差 | 只统计已采纳、已执行且完成归因的方案 |
