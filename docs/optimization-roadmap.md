# 30/60/90天试点路线

## 30天：四类数据校核

首月不承诺打通全部生产系统，只校核以下四类离线或只读数据：

1. ERP或经营系统导出的订单数据。
2. MES班次计划。
3. 罐区历史摘要。
4. 飞书协同记录。

逐字段确认来源、时间戳、单位、质量状态、更新频率和责任专业；形成字段字典、样例、质量报告和后续接口清单。该阶段不接入DCS实时写路径，不使用样例数据计算企业实际效果。

## 60天：只读扩展与旁路回放

- 在企业批准后接入生产历史数据库、设备软件和公用工程的只读数据。
- 对正常班次、急单、库存偏低和设备趋势异常场景进行历史回放。
- 将平台建议与当时人工方案比较，记录差异、未采纳原因和输入适用工况范围。
- 验证设备趋势提示与DCS报警的显示和职责边界。

交付物：旁路回放报告、人工方案对照表、数据缺口清单、停用条件和候选规则审核记录。

## 90天：条件受控执行验证

- 仅选择数据可信、审批路径明确、未命中演练停算线且不触碰控制回路的场景。
- 覆盖不少于30个有效班次，以及产供销重排、公辅波动吸收、设备趋势复核三类场景。
- 经人工审批后写入MES计划摘要，并通过飞书Task v2跟踪责任人、截止时间和复盘结果。
- 审批通过后向合成主操、硝酸主操、罐区/调度和公辅调度分别派发动作单；四岗位全部接令后才进入执行跟踪。
- 对比建议值与生产历史数据库只读回传的实际值。
- 接令不等于实际执行；Historian未回传时实际值保持为空，不进入效果统计。
- 核对相对外售分配贡献测算值、执行偏差和外部影响，不称为已实现收益。

交付物：执行验证报告、审批与任务记录、班后复盘、规则版本和下一阶段范围建议。

## 验收与停用

- 验收前由双方确认基线期、评价期和指标阈值。
- 安全硬约束零突破、数据质量、建议可复算、审批合规、四岗位接令门禁及“无Historian回传时实际值为空”为必过项，再比较订单满足率、单位氨变动成本、库存占用、调度用时和设备趋势提示提前量。
- 数据过期、质量状态无效、输入超出适用工况范围、模型偏差超过确认控制限，或安全与设备限值接近时，停止给出可执行建议并转人工处理。
- 24小时指标统一称为相对外售分配贡献测算值；实际效果只统计已采纳、已执行且完成归因的方案。

## 预登记验收目标

| 指标 | 定义稿口径 | 目标 |
| --- | --- | --- |
| 数据可用率 | 在约定新鲜度窗口内、质量状态合格的必需记录数 / 应到必需记录数 | 不低于98% |
| 物料平衡残差 | `|期初可用量+期间产量+外采-各去向-期末可用量| / (期初可用量+期间产量+外采)` | 不高于1.5% |
| 快照重算P95 | 从合格输入快照冻结到候选方案、约束证据和测算明细生成完成的95分位耗时，不含人工确认 | 不高于120秒 |
| 调度决策中位耗时缩短 | `1-试点同类场景决策中位耗时/基线中位耗时` | 不低于30% |

以上是试点定义稿，不表示当前已达成。30天阶段完成字段、分母、时间起止点、场景分层、基线期和排除项校核后，由企业冻结最终验收口径。
