# 氨智领航调控师产品展示包

本展示包用于企业领导和决赛现场快速了解作品。建议先播放 PPT，再根据提问打开网页对应模块。

## 文件说明

- `氨智领航调控师_产品全景与决赛展示.pptx`：14 页主汇报，按照一次班次从事实进入、形成方案、组织执行、影子验收、经验沉淀的顺序展开。
- `氨智领航调控师_产品全景与决赛展示.pdf`：与主汇报一致的14页只读备份，便于没有PowerPoint的设备打开。
- `氨智领航调控师_产品功能全景树.png`：高清功能树，适合单独放大查看或插入其他材料。
- `氨智领航调控师_产品功能全景树.svg`：可继续编辑的矢量源文件。
- `氨智领航调控师_逐页讲解稿.md`：每页可直接使用的现场讲法、常见追问和网页演示顺序。
- `PPT最终回读预览.png`：最终 PPTX 重新渲染后的全页预览，用于会前快速检查。
- `screenshots/`：15 张当前网页实拍及一张总览。

## 一条主线看懂作品

`统一班次事实 → 校核安全与物料 → 比较产供销和稳产方案 → 班长/专业确认 → 飞书任务与岗位接令 → 实际回传 → 影子验收 → 专业审核后进入学习库`

平台部署在生产运行管理层，不写 DCS/SIS，不替代联锁、操作票、班长和专业会签。页面中的价格、库存、负荷、设备趋势和收益均为验收样例；企业实际效果必须在只读接入真实班次数据后验证。

## 建议展示顺序

1. 用 PPT 第 2 页功能树建立全局认识。
2. 打开网页“当班态势”，说明平台的位置和四种场景。
3. 进入“产供销平衡”，演示行情闸门、液氨平衡和经济取舍。
4. 进入“稳产预警”，演示设备弱信号和责任专业。
5. 进入“执行复盘”，演示跨装置动作单、飞书协同和经验学习。
6. 进入“依据与接入”，演示影子运行和 30/60/90 天试点路线。
